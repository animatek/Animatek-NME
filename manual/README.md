# Animatek NME User Manual

Animatek NME is a modern editor for the **Clavia Nord Modular G1** synthesizer.
This manual covers installing the editor, connecting your synth, and everything
you can do once you're in.

> Nord Modular is a trademark of Clavia DMI AB. This project is an independent,
> community-developed editor and is not affiliated with or endorsed by Clavia.

## Quick orientation

If you've used the original Clavia editor or Nomad/nmedit, you'll feel at home:
the patch canvas with its Poly and Common areas, cable colors, module palette and
slot workflow all follow the original. What's new is everything around them:
disk preset browser, bank tools, patch mutator, variations, themes, module
presets, tiled sub-windows for editing several slots at once, an optional
AI-assistant bridge, and a protocol layer verified against real hardware.

If you're new to the Nord Modular, start with [Getting Started](01-getting-started.md)
and then skim [Editing Patches](03-editing-patches.md); the rest can wait until
you need it.
