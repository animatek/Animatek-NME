# Manual de usuario de Animatek NME

Animatek NME es un editor moderno para el sintetizador **Clavia Nord Modular
G1**. Este manual cubre la instalación del editor, la conexión con tu
sintetizador, y todo lo que puedes hacer una vez dentro.

> Nord Modular es una marca registrada de Clavia DMI AB. Este proyecto es un
> editor independiente desarrollado por la comunidad y no está afiliado ni
> respaldado por Clavia.

## Orientación rápida

Si has usado el editor original de Clavia o Nomad/nmedit, te sentirás en casa:
el canvas de patch con sus áreas Poly y Common, los colores de cable, la paleta
de módulos y el flujo de slots siguen al original. Lo nuevo es todo lo que los
rodea: navegador de presets en disco, herramientas de banco, patch mutator,
variaciones, temas, presets de módulo, subventanas en mosaico para editar varios
slots a la vez, un puente opcional para asistentes de IA, y una capa de protocolo
verificada contra hardware real.

Si el Nord Modular es nuevo para ti, empieza por
[Primeros pasos](01-getting-started.md) y luego echa un vistazo a
[Editar patches](03-editing-patches.md); el resto puede esperar hasta que lo
necesites.
