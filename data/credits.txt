Animatek NME is a native reimplementation of the Nomad editor for the
Clavia Nord Modular G1, written in C++ with JUCE.


BUILT ON THE WORK OF

  The original nmedit / Nomad developers, without whose reverse
  engineering this editor could not exist:

  Marcus Andersson      Nord Modular MIDI protocol; C++ and Java
                        protocol libraries
  Christian Schneider   Nomad Java editor v0.2 / v0.3
  Ian Hoogeboom         Nomad v0.4 and macOS compatibility
  Jan Punter            Patch file format documentation
  Jelle Herold          Original project founder
  Stefan Keel           Module icon designs
  Tobias Weinald        Splash screen artwork

  nmedit.sourceforge.net
